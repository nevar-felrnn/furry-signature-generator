          How to install
          

            
Apple Mail

            
Click Copy signature. In Mail, go to Settings → Signatures, click +, untick “Always match my default message font”, then paste into the right-hand pane.

            
Thunderbird

            
Save .html and keep the file somewhere permanent. In Account Settings, tick “Use HTML” and “Attach the signature from a file instead”, then choose the file.

            
Gmail

            
Gmail removes uploaded (embedded) images when you paste. Switch the logo to Hosted URL, then copy and paste into Settings → General → Signature.

            
Outlook

            
Use a Hosted URL logo. Paste into Settings → Mail → Signatures (or File → Options → Mail → Signatures on desktop).
